# 🍔 Hamburgueria — Landing Page

Uma landing page moderna, atraente e totalmente responsiva para uma hamburgueria artesanal fictícia. O projeto foi desenvolvido com foco em alta conversão, boa experiência do usuário (UX) e design limpo.

## 🚀 Tecnologias Utilizadas
* **HTML5** (Estruturação semântica)
* **Css** (Estilização responsiva e moderna)
* **JavaScript** (Interatividade e animações)

## ✨ Funcionalidades
* Menu de navegação responsivo com menu móbile
* Seção de destaques e cardápio interativo por categorias
* Seção "Sobre Nós" contendo os diferenciais da marca
* Depoimentos de clientes e seção de perguntas frequentes (FAQ)
* Informações de contato, horário de funcionamento e localização
* Botões de chamada para ação (*CTA*) direcionados para pedidos online
